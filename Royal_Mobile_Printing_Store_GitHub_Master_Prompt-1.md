# Royal Mobile And Printing Store

# 1. Core Owner-First Principle

The owner must manage routine business operations from one centralized **Owner Panel** without editing source files, writing prompts, creating files, or manually changing GitHub code every day.

Owner Panel must provide appropriate controls for all implemented modules:
- Add
- Edit
- Delete
- Duplicate
- Customize
- Enable / Disable
- Configure
- Preview
- Save
- Publish
- Import / Export where applicable

Settings must be persisted in the database and remain after refresh, sign-out, or application restart.

**Technical truth:** Existing features and business settings can be managed from the Owner Panel. A genuinely new code-level software feature still requires code, testing, and deployment. Implement a secure automated release/deployment pipeline for that work; do not falsely promise that arbitrary new functionality can be generated by a setting alone.

# 11. Customer-Created Custom Product Requests (Up to 20 Images)

Customers can request a product that is not already in the catalog.

Request form:
- Customer name
- Mobile/WhatsApp number
- Email (where applicable)
- Product name/type/category
- Complete product description
- Size, color, material, dimensions
- Quantity
- Budget (optional)
- Desired date (optional)
- Printing/customization method and details
- Text/logo/design instructions
- Reference pictures
- Additional notes

Image upload:
- Allow up to **20 pictures per request**.
- Provide upload progress, previews, remove/replace controls, and validation.
- Enforce configurable file-size limits and allowed formats (at least common safe image formats such as JPEG, PNG, and WebP; add other formats only if safely supported).
- Validate file contents, not only extension.
- Store files securely and associate them with the correct request.
- Protect against malicious files and unauthorized access.
- Keep customer images private by default.
- Provide authorized owner download/view access.

Workflow:
1. Customer fills complete details.
2. Uploads up to 20 images.
3. Reviews and submits request.
4. Owner reviews details and images.
5. Owner adds notes and quote, including product cost, production cost, delivery charge, and timing.
6. Customer accepts/rejects quote.
7. Accepted quote can become a real order.
8. Track production, fulfillment, and delivery.

Statuses:
- Submitted
- Under Review
- Quotation Sent
- Approved
- In Production
- Quality Check
- Ready
- Shipped
- Delivered
- Rejected
- Cancelled

Owner can edit/manage requests, quote, approve/reject, set prices/costs/timelines, download authorized reference images, and convert approved requests into orders.
