# Royal Marketplace — GitHub Pages demo package

Responsive e-commerce front end tailored to Royal Marketplace, Faisalabad, Punjab, Pakistan (support 03040011041).

## Features included
- Product grid/catalog, seeded example products, category filter, search and sorting
- Cart quantity update/removal, wishlist
- Demo customer profile, checkout, order history
- Order tracking
- Admin product add/edit/delete and order status management
- Seller listing request, return/refund request forms
- Responsive styles for desktop/mobile

## GitHub Pages upload
Extract ZIP. Upload **all files and folders** into the repository root, preserving `assets/`. Commit. Go to repository Settings → Pages → Deploy from branch → select `main` and `/ (root)`. Refresh the site with Ctrl+F5.

## Honest scope
This is a GitHub Pages browser demo. The demo uses `localStorage`, so products/orders/profile/admin changes are stored on the same browser and device, not a shared server. Demo checkout does not charge money. Admin page has no secure login. There is no live payment gateway, shipping provider, true multi-vendor backend, or permanent cloud database. Those need a deployed server, database, secure authentication, and payment/shipping integration. GitHub Pages itself hosts static files only.
