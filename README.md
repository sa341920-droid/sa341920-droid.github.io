# Royal Mobile And Printing Store

A responsive starter storefront for Royal Mobile And Printing Store (Faisalabad, Punjab, Pakistan).

## Included
- Responsive storefront with category/product catalog
- Search and category filtering
- Demo cart (browser-only)
- Custom product request form with reference-image selection (front-end preview only)
- Shop contact details and WhatsApp link
- Owner dashboard starter for managing demo products and viewing locally stored custom requests
- Theme selector with 20 visual themes
- Editable demo catalog stored in browser localStorage

## Important limitations
This is a **front-end starter project**, not a production-ready e-commerce platform. The included browser storage is local to the device/browser and is not a secure shared database. There is no real payment gateway, account authentication, server-side order creation, email/SMS delivery, secure file storage, scheduled backup, social-media publishing API, AI integration, or live inventory synchronization yet. Do not accept payments or treat demo cart actions as confirmed orders.

## Run
Open `index.html` in a browser, or use a local static server.

## GitHub Pages
1. Upload the contents of this folder to the repository root (not the ZIP itself).
2. In GitHub, open **Settings → Pages**.
3. Set source to **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save and wait for the deployment.
5. Visit `https://sa341920-droid.github.io/`.

## Owner dashboard
Open `owner.html`. Demo changes are stored in this browser only. For secure multi-user use, connect a real backend/database and authentication.

## Next production work
